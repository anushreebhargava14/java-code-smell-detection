# ML-Based Code Smell Detection

A machine learning system that detects code smells (Long Method, God Class, Data Class, Feature Envy)
in Java source code, built as a B.Tech CSE final year project.

## Project Status
Stage 0 — Project setup complete.

## Dataset
Primary dataset: MLCQ (Madeyski & Lewowski, 2020) — human-labeled Java code smell reviews.
https://doi.org/10.5281/zenodo.3666840

## Setup

```bash
python3 -m venv venv
source venv/bin/activate   # or venv\Scripts\activate on Windows
pip install -r requirements.txt
```
