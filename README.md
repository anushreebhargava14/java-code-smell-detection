# ML-Based Code Smell Detection

A machine learning system that detects code smells (Long Method, God Class, Data Class, Feature Envy)
in Java source code, built as a B.Tech CSE project.

## Project Status

Stage 0 — Project setup.

## Dataset

Primary dataset: MLCQ (Madeyski & Lewowski, 2020) — human-labeled Java code smell reviews.
